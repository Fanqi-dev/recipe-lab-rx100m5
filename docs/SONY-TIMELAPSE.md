# Sony Time-lapse 3.40 local2

基于用户提供的 `11.apk` 的非官方修补测试版，保留索尼原有菜单、资源和机内视频合成；不是 Jonas 的开源 TimeLapse，也不是索尼发布的新版本。

## 改动

- 设置页按当前选项显示一行短提示；空间不足时隐藏，避免覆盖确认/取消。
- 拍摄间隔与持续时间改用单调时钟，避免系统时间变化干扰。
- 自定时取消只执行一次；DSP 初始化失败时防止空对象释放。
- AVI 回放拒绝无效索引；缩略图行控件复用，释放窗口外缓存的持有引用，移除重复刷新与高频调试堆栈开销。

缩略图解码仍同步执行，原有视频编码及硬件同步流程未改。没有增加插帧或 60p，也未实测速度提升。

## 安装限制

原包为 `com.sony.imaging.app.timelapse`，版本 3.40；用户提供的输入带 Android Debug 证书，未验证为索尼原始签名发行包。修补包已本地重签，不能直接覆盖不同签名的原版。

**不要为安装而卸载原版、清除数据或删除 APP_TLPS。** 需先完成备份与迁移安排，未确认前不要替换。

此闭源应用不适用本仓库 MIT 许可；修补包不是索尼官方授权发布。未进行相机实机验收，验证范围见 [验证记录](../VERIFICATION.md)。
